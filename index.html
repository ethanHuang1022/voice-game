🎤 Cody的聲控遊戲館

用你的聲音來玩！第一次進入遊戲時，瀏覽器會詢問麥克風權限，請按「允許」。建議使用 Chrome 或 Edge。

🐤

聲控小鳥

音量越大飛越高，安靜就往下降。穿過水管，共 3 關。
🗣️

英文發音闖關

聽系統念出單字或句子，念對了頭像就能穿過洞口往上爬。120 個單字＋隨機句子，共 6 關（含地獄級繞口令）。
🎵

音準挑戰

聽目標音，用聲音唱到同一個音並穩住。單音 → 音程 → 小星星旋律，共 3 關。
🏃

語音跑酷

喊「左、右、跳、蹲」或 left / right / jump / duck 控制角色閃避障礙，共 3 關。
🍄

聲控大冒險

有聲音就前進、越大聲越快，突然大聲就跳、越大聲跳越高，安靜時會往回走。吃火焰花後說「fire」或「發射」發射火焰。共 8 關含 2 場魔王戰，記錄過關時間。
